# ROW Guild War Manager

เว็บจัดการข้อมูลกิลวอสำหรับ Ragnarok: The New World แบบ static เปิดใช้งานได้ทันที และเหมาะสำหรับนำขึ้น GitHub Pages

## ฟีเจอร์

- ใช้ Bootstrap 5 ผ่าน CDN
- สลับภาษาไทย / อังกฤษได้
- รายชื่อสมาชิก แยกกลุ่มตามอาชีพ
- จัดสนามหลักและสนามรองเป็นปาร์ตี้ละ 5 คน
- ช่องปาร์ตี้ดึงอาชีพ บทบาท และหมายเหตุจากข้อมูลสมาชิกอัตโนมัติ
- แจ้งลาวอพร้อมวันที่และเหตุผล
- เช็คชื่อกิลวอแยกตามวันที่
- บันทึกข้อมูลในเบราว์เซอร์ด้วย `localStorage`
- มี log ประวัติการเปลี่ยนแปลง
- Export / Import ไฟล์ JSON สำหรับสำรองหรือย้ายเครื่อง

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรัน local server:

```bash
npx serve .
```

## การลง GitHub Pages

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
3. ไปที่ Settings > Pages
4. เลือก Deploy from a branch
5. เลือก branch `main` และ folder `/root`

## การเก็บข้อมูล

ข้อมูลถูกเก็บใน `localStorage` ของเบราว์เซอร์ผู้ใช้ จึงยังอยู่หลังปิดหน้าเว็บหรือรีเฟรช แต่ข้อมูลจะผูกกับเครื่องและเบราว์เซอร์นั้น ๆ

แนะนำให้กด `Export` เป็นประจำเพื่อสำรองข้อมูลเป็นไฟล์ JSON และใช้ `Import` เมื่อต้องการย้ายข้อมูลไปเครื่องอื่น
